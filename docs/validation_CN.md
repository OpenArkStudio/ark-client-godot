# 验证范围

2026-10-26 与 2026-10-27 的本地验证使用 Apple M4 Pro、14 核 CPU、48 GiB 内存、macOS 27.0.1 arm64、Godot
`4.7.2.stable.mono.official.ed1daf0bf`、.NET SDK `10.0.403` 和 .NET 运行时 `8.0.33`。
所有项目均以 `net8.0` 为目标。常规 .NET 8 SDK 包含匹配的运行时与引用包；
本地 SDK 10 环境还原了官方 .NET 8 引用包，并在运行时 10 之外保留匹配的 .NET 8 运行时。

| 检查 | 结果 |
| --- | --- |

| Godot C# 解决方案构建 | 通过，零警告、零错误 |
| 官方 .NET 编辑器无界面导入 | 通过 |
| 离线引擎场景执行 | 通过，输出明确的 C# 场景就绪标记 |
| 原生窗口界面检查 | 通过：两个真实玩家、村庄素材、不同的 YOU／PLAYER 文字及标记、键盘移动，网络详情默认收起 |

双客户端检查使用真实 ark 启动器和示例插件，以及 Net、Bus、Utility 与 Kernel，
没有以独立 TCP 服务端替代框架路径。本地原始日志保留在版本控制之外。
[运行文档](run_CN.md) 中的脚本可对匹配的示例服务端复现客户端检查。
