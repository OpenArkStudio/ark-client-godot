# 有界本机多进程持续验收

使用 .NET 8 和专用空大厅的 guest-room 服务端。按[运行指南](run_CN.md)选择仓库外的
工具；服务端由操作者启动和停止。

```sh
DOTNET=/path/to/dotnet bash tools/soak-three-clients.sh 127.0.0.1 19100 600
```

默认持续 600 秒，接受 30–3600 秒。脚本串行构建；若已有匹配的测试 DLL，可追加
`--no-build`。

| 模式／产物 | 行为 |
| --- | --- |
| 常驻客户端 | Alice、Bob 各保持一条连接；三方均入房后才开始计时 |
| Churn | 约每五秒重连；提前五秒结束，让常驻方确认删除 |
| 活动 | 约每 250 ms 请求一次移动、动作及心跳；动作循环为受伤、技能、恢复和封顶恢复 |
| 断言 | 八秒内确认匹配的位置／序列号、HP／MP、nonce；重连身份／基线更新；观察每次 churn 加入／删除；不重试或重放 |
| 进程管理 | 首个客户端非零退出即终止并回收其余进程；已回收 PID 在后续信号前退役；给予五秒退出宽限后强杀仍未退出的子进程 |
| 证据 | 临时目录保存日志、计数、退出码、PID 和约每秒一次的 CPU／RSS 采样；`bash tools/test-soak-runner.sh` 无网络检查子进程失败 |

**2026-11-03** 本地验收使用 Apple M4 Pro、14 核、系统报告的 48 GB 内存、macOS
27.0.1 arm64、SDK 8.0.427／运行时 8.0.33，以及回环端口 19531。
服务端使用 Debug／Apple clang 21.0.0；客户端使用 Google.Protobuf 3.33.4。

| 600 秒输入 | 身份 |
| --- | --- |
| ARK 服务端 | `c9aa911a4893ffa2681925e8ebf13e703f8f4c16`；逐字节核对六个候选镜像，并检查实际加载镜像 |
| 客户端输入 | 构建 `9f4a8f91da260a562e34f5ff02e1a4139a7440d7`；执行 `1e6181e160b663cffec3e032f75fc1dc778d4326`；C# 输入逐字节一致 |
| 测试 DLL SHA-256 | `18b273b56634903c52aca19b7ca3d7ff5baa4a65919a15998b8f2251f196fb5c`；使用 `--no-build`，运行前后哈希一致 |

| 进程 | 活动秒数 | 连接数 | 新身份重连数 | 已确认活动轮数 |
| --- | ---: | ---: | ---: | ---: |
| Alice | 600.141 | 1 | 0 | 2374 |
| Bob | 600.137 | 1 | 0 | 2374 |
| Churn | 595.105 | 112 | 111 | 2348 |

最大同时入房人数和采样到的已建立连接均为三。各 7096 次移动、动作和心跳均得到
确认，业务／协议失败为零；两个常驻客户端均观察到全部 112 次 churn 加入／删除。

| 检查 | 结果 |
| --- | --- |
| 600 秒活动 | 三个客户端均退出 0，跨进程检查通过；原包装器随后因 Bash PID 数组清理退出 1 |
| 30 秒进程监督 | 端口 19533：确认 337 轮活动，包装器、客户端及计数检查均退出 0；不改写 600 秒回执 |
| 服务端关闭 | SIGINT 退出 0，没有强杀；监听端口及自有进程均退出 |

| 进程 | 平均 CPU，% | 采样峰值 CPU，% | 30–60 秒 RSS，MiB | 最后 30 秒 RSS，MiB | 采样峰值 RSS，MiB |
| --- | ---: | ---: | ---: | ---: | ---: |
| 服务端 | 10.13 | 15.6 | 42.03 | 42.23 | 42.23 |
| Alice | 11.87 | 25.8 | 59.59 | 62.22 | 62.45 |
| Bob | 12.01 | 25.8 | 59.48 | 62.13 | 62.38 |
| Churn | 11.40 | 25.3 | 60.59 | 64.17 | 64.20 |

平均 CPU 为进程累计 CPU 时间除以观测墙钟时间，100% 表示一个逻辑核。
RSS 列为对应窗口的采样均值，每 MiB 为 1024 KiB。同一主机还有其他本地验收，
不属于隔离环境下的吞吐／延迟基准测试。

这是便携 C# 的有界工作负载，不验收 Godot 场景、导出包、跨主机行为或生产 PCU 容量，
也不能证明没有泄漏。完整二进制清单和原始回执留在本机，其他检查见[验证记录](validation_CN.md)。
