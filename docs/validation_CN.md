# 验证范围

2026-10-26 与 2026-10-27 的本地验证使用 macOS arm64、Godot
`4.7.2.stable.mono.official.ed1daf0bf`、.NET SDK `10.0.403` 和 .NET 运行时 `8.0.33`。
所有项目均以 `net8.0` 为目标。常规 .NET 8 SDK 包含匹配的运行时与引用包；
本地 SDK 10 环境还原了官方 .NET 8 引用包，并在运行时 10 之外保留匹配的 .NET 8 运行时。

| 检查 | 结果 |
| --- | --- |
| 永久编译执行的 C# 检查 | 9 组通过，覆盖共享向量、全部分割边界、合并消息帧、长度上限、无效消息头、无效状态拒绝、有界标签布局、真实 TCP 与重连 |
| Godot C# 解决方案构建 | 通过，零警告、零错误 |
| 官方 .NET 编辑器无界面导入 | 通过 |
| 离线引擎场景执行 | 通过，输出明确的 C# 场景就绪标记 |
| 两个无界面 .NET 引擎客户端连接真实 ark 访客房间示例 | 通过：双方加入、观察服务端确认的移动、以新 ID 重新加入，并观察另一客户端的新 ID |

双客户端检查使用真实 ark 启动器和示例插件，以及 Net、Bus、Utility 与 Kernel，
没有以独立 TCP 夹具服务端替代框架路径。本地原始日志保留在版本控制之外。
[运行文档](run_CN.md) 中的脚本可对匹配的示例服务端复现客户端检查。

本记录不代表可见界面检查、托管 CI、桌面导出安装包、部署、账号认证、持久身份、
跨主机网络或生产容量验证。这些事项需要独立证据。

仓库包含 GitHub Actions 跨平台可移植代码检查，以及 Linux 离线 Godot .NET 检查。
本地记录不表示这些托管任务已运行或通过。
