# 有界本机多进程持续验收

> **PENDING：**[5,000 连接调查](https://github.com/OpenArkStudio/arknet/issues/61)已暂缓。当前嵌套 Entity 协议的持续验收仍须等待该问题修复并通过。下方短功能结果不属于持续运行验收。

使用 .NET 8 和采用当前匹配[协议](protocol_CN.md)的专用空大厅服务端；服务端由操作者启动和停止。
连接问题解决且明确安排运行后，按[运行指南](run_CN.md)选择仓库外工具：

```sh
DOTNET=/path/to/dotnet bash tools/soak-three-clients.sh \
  127.0.0.1 19100 600 /absolute/local/soak-run
```

持续时长必须显式提供，范围为 30–3600 秒。输出目录也必须显式提供：Git 仓库之外的绝对本地路径，
目录尚不存在或为空。已有证据不覆盖，原始日志／指标不作为发布资产。脚本串行构建；只有已有匹配的测试
DLL 时才追加 `--no-build`。输出记录源码 HEAD／状态、两个客户端程序集 SHA-256、工作负载计数、
进程退出码／PID 和每秒 CPU／RSS 采样。服务端修订、二进制、配置与停止回执需另行记录。

| 模式／边界 | 行为 |
| --- | --- |
| 常驻方 | Alice、Bob 各保留一个连接；三方均入房后才开始计时 |
| 完整循环 | 12 次移动／动作／心跳，目标每步 250 ms：受击、技能、恢复、封顶恢复、喝药两次、收集两次、切换、强化、切回、强化 |
| 双方视图 | 观察每个已提交消息；两名常驻方每步均等待对方的移动／动作阶段通过校验后才前进 |
| 嵌套断言 | 数量补丁、最后一行删除、更大 incarnation 的行复用；装备替换、保持 GUID／incarnation 的子装备 power 更新、回槽装备强化值保留 |
| Churn | 每两个完整循环重连，约六秒加重连耗时；预留暂停与收尾时间，验证根／装备新身份及初始状态，失败后不重试 |
| 时长计划 | 常驻方向上取整到完整三秒循环，计划时长最多比请求多两秒；Churn 预留五秒与每次 250 ms 重连间隔 |
| 失败边界 | 活动／协调截止时间八秒，计划时长后十五秒工作负载宽限；包装器 watchdog 有限，最多请求时长加六十秒 |
| 进程管理 | 首个客户端非零退出即停止并回收其余进程；不再向退役 PID 发信号，给予五秒退出宽限后仅强杀尚未退出的自有子进程 |

完整循环的每一步都确认移动、动作及匹配 pong。跨进程检查核对完整循环、精确动作／行／容器操作计数、
子补丁计数（允许封顶空操作）、双方进度及全部
Churn 加入／删除。包装器不停止服务端或其他进程，不提供无限运行，也不自动重试到通过。

不连接服务端即可准备：

```sh
/path/to/dotnet build tests/Ark.Client.Core.Tests/Ark.Client.Core.Tests.csproj --disable-build-servers -m:1
/path/to/dotnet tests/Ark.Client.Core.Tests/bin/Debug/net8.0/Ark.Client.Core.Tests.dll --soak-workload
TMPDIR=/absolute/local/test-temp bash tools/test-soak-runner.sh
```

永久 C# 小测试覆盖有限计划和合法／非法嵌套状态转换，包括 power 封顶与生命周期回退。Shell fixture
在无网络条件下检查失败、中断和拒绝退出的子进程。这些检查只编译／验证工具，不证明持续服务端运行、
Godot 场景或导出包。

## 此前协议的历史结果

下方日期记录使用此前协议输入，不代表当前嵌套契约已通过持续运行验收。

**2026-11-03** 本地验收使用 Apple M4 Pro、14 核、系统报告的 48 GB 内存、macOS
27.0.1 arm64、SDK 8.0.427／运行时 8.0.33，以及回环端口 19531。
服务端使用 Debug／Apple clang 21.0.0；客户端使用 Google.Protobuf 3.33.4。
